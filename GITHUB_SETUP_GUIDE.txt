MONEYMANTRA 9 — GITHUB PAGES PWA SETUP

OPTION A — FREE GITHUB PAGES ADDRESS
Example:
https://YOUR-GITHUB-USERNAME.github.io/moneymantra9-mf-research/

1. Create or sign in to your GitHub account.
2. Click the + button in the top-right corner, then New repository.
3. Repository name:
   moneymantra9-mf-research
4. Select Public.
5. Do not add a README, .gitignore, or licence while creating it.
6. Click Create repository.
7. On the empty repository page, click:
   uploading an existing file
8. Open this extracted folder on your computer.
9. Select ALL files INSIDE this folder and drag them into GitHub.
   index.html must be visible at the top level of the repository.
10. Enter commit message:
    Initial MoneyMantra 9 MF Research PWA
11. Click Commit changes.
12. Open repository Settings.
13. In the left sidebar, open Pages.
14. Under Build and deployment:
    Source: Deploy from a branch
    Branch: main
    Folder: /(root)
15. Click Save.
16. Wait a few minutes, then refresh the Pages screen.
17. GitHub will display the published site address.

IMPORTANT:
- Do not upload the ZIP itself.
- Do not upload an outer folder containing index.html.
- index.html, app.js, data.js and service-worker.js must be at repository root.
- The repository must be Public when using GitHub Free Pages.

OPTION B — USE A SUBDOMAIN OF MONEYMANTRA9.COM
Recommended address:
https://mf-research.moneymantra9.com/

Complete Option A first, then:

1. In GitHub repository:
   Settings > Pages > Custom domain
2. Enter:
   mf-research.moneymantra9.com
3. Click Save.
4. Open the DNS management panel for moneymantra9.com.
5. Add a CNAME record:
   Type: CNAME
   Host/Name: mf-research
   Value/Target: YOUR-GITHUB-USERNAME.github.io
   TTL: Automatic or 1 hour
6. Do not include https:// and do not add the repository name in the CNAME target.
7. Wait for DNS propagation.
8. Return to GitHub Pages settings.
9. Enable Enforce HTTPS when it becomes available.

A PATH SUCH AS:
https://www.moneymantra9.com/mf-research/
cannot be created with DNS alone.
To use that path, the PWA files must be uploaded to the existing website hosting
inside a folder such as public_html/mf-research, or the web server must be
configured as a reverse proxy.

UPDATING THE APP LATER
1. Open the GitHub repository.
2. Click Add file > Upload files.
3. Upload the updated files.
4. Replace files with the same names.
5. Commit the changes.
6. GitHub Pages republishes automatically.

IPHONE INSTALLATION
1. Open the published HTTPS link in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Tap Add.

ANDROID INSTALLATION
1. Open the published HTTPS link in Chrome.
2. Open the browser menu.
3. Tap Install app or Add to Home screen.
